## 🏮 Featured Project

### 楽天市場 — Rakuten Ichiba, Reimagined
A production-grade clone of Rakuten's marketplace — built to study and reproduce the UX patterns that make Japanese e-commerce structurally different from Western retail: point-economy loyalty, seller-first storefronts, information-dense layouts, and Japanese-as-source-of-truth bilingual UX.

`React 18` · `TypeScript` · `Supabase` · `PostgreSQL RLS (33 policies)` · `100% i18n coverage (EN・日本語)` · `AI shopping assistant`

**[→ View the repo](https://github.com/iTanmayTrivedi/RakutenJapan)**
